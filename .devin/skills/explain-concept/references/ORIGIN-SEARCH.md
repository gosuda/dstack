# Where the idea came from

Some explanations deserve one short paragraph on who introduced the concept and what it replaced. This note covers how to find that source and how to write it down. Nothing here lands in the explanation until the user accepts a candidate.

## Searching for the source

Build the query from the concept name and its field: `"{concept}" origin history {field}`. Prefer a venue page or an author page when one appears in the first results.

## Proposing candidates

Put at most three candidates in a table and wait for the user to accept one:

| Title | Author | Year | Venue | URL |
|---|---|---|---|---|
| {title} | {author} | {year} | {venue} | {url} |

An auto-picked citation is not a citation. Nothing is written until the user accepts a candidate.

## Writing the origin note

Write the accepted candidate as one paragraph under `## Origin`:

```md
## Origin

{Concept} was introduced by {author} in {year} ({venue}), displacing {what it replaced}. For the source: {URL}.
```

Keep title, author, year, and URL in the paragraph. Paraphrase the history; quote only a coined term or a named law, where the exact phrasing is the idea.

If the user declines every candidate, the origin angle ends there and the rest of the explanation is unaffected.
